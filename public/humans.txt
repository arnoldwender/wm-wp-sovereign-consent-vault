# TECHNOLOGY COLOPHON

    ## Architecture & Core
    WordPress 6.4+ / 7.x
    PHP 8.2+ (Strict Types, PSR-12, WPCS)
    MySQL InnoDB (two plugin tables)
    WP-CLI command and REST routes

    ## Frontend
    Vanilla JS (assets/js/wm-consent-vault.js, admin inline scripts)
    CSS custom properties for the consent dialog and the click-to-load placeholder
    Self-Hosted Assets (no CDN)

    ## Quality
    HMAC-SHA256 chained log of consent decisions, two signature formats
    Output-buffer blocking of registered services before consent
    Standalone test suites on PHP 8.2 and 8.3, mutation gate
